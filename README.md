# Three offline AI project starters

Three small AI projects, each self-contained and API-free.

| Project | Stack | What it does |
|---|---|---|
| [`sentiment-analysis/`](./sentiment-analysis) | sklearn + Streamlit | TF-IDF + Logistic Regression sentiment classifier with a live UI |
| [`resume-parser/`](./resume-parser) | spaCy + PyMuPDF + Streamlit | Extracts contact info, skills, and sections from PDF/TXT resumes |
| [`ai-meeting-notes/`](./ai-meeting-notes) | faster-whisper + Streamlit | Local audio transcription → extractive summary + action items |

Each folder has its own `requirements.txt` and `README.md`. Install into a fresh virtualenv per project.
