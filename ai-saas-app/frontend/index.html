Summarize-as-a-Service

Sign up for a key, POST text, get an extractive summary. FastAPI + SQLite + a homegrown TF-IDF summarizer.

1. Get an API key

2. Summarize

3. History

    API docs: /docs

    Curl example:

    curl -X POST http://localhost:8000/summarize \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sk_..." \
  -d '{"text":"...", "sentences":5}'
